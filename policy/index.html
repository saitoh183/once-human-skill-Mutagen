Privacy Policy

Last updated: June 2026

Once Human Skill Mutagen is a small reference app. It does not require user accounts and does not intentionally collect personal information from public users.

Information stored in your browser

The app may use local browser storage for interface preferences such as theme selection. Editor/admin pages may prefill locally saved edit/admin keys if you chose to store or use them in that browser.

Hosted database

The public app loads deviation/skill data from Cloudflare Pages Functions and D1. Public users only read this data. Authorized editors can update the shared database using an edit key.

Server and platform logs

Cloudflare may process standard request metadata such as IP address, user agent, requested URL, timestamps, and security/performance logs as part of hosting the site.

No sale of data

This project does not sell personal information.

Third-party assets

The app may display game-related names or icons for reference. Those assets belong to their respective owners.

Contact

For privacy questions or removal/correction requests related to project content, use the GitHub repository issue/discussion flow where available.
